🤖 TeamBot — 產品需求 (PRD v2)

用手機 Microsoft Teams 遠端操作電腦上的常駐 Codex CLI:交辦、看進度、做決策、取回結果。借鏡開源 telecodex(Telegram↔Codex)。2026-09-24

核心價值

離開電腦也能用手機交辦與監控本機 Codex;常駐工作階段保留對話上下文,危險操作需你批准。

資料區

D:\AgentHub 為個人助理工作區(projects / data / logs);寫入預設限縮於此。

系統架構

Teams / 傳輸 TeamBot 服務 Codex / 檔案 安全關卡

電腦主動連出;手機不直接連入電腦。與 telecodex 差異:Telegram 有官方 Bot API,Teams 走 CDP 自有表面(有條款風險,長期評估 Graph/Bot Framework)。

一次互動流程(含決策關卡)

長任務期間會定期回報合併狀態卡(就地編輯、≤1/間隔、心跳);!tb status 隨時拉快照。

指令模型

指令作用狀態
!tb <自然語言> / run交辦(預設 AgentHub)已實作
status / result / diff狀態 / 結果 / 變更status ✅
approve / deny / answer決策(繫結代碼、逾時自動拒)已實作
unlock [分] / lock / kill切換寫入姿態 / 硬停已實作
steer / continue / stop中途追加 / 續輪 / 收尾停引擎✅
use latest / sessions / new切換/開新/列出 session規劃(借鏡)
login / logoutCodex 裝置登入規劃(借鏡)

借鏡 telecodex 的 v2 需求

H · 串流回覆就地編輯

單訊息編輯 + debounce + 分段 + 限流退避(edit_debounce_ms / max_text_chunk / retry_after)。

I · 多會話 / 切換 thread

use latest、sessions、new;每對話一 session(topic-aware)。

J · 附件 in/out

.teambot/inbox 收檔、turns/out 自動回傳產物。

K · 歷史匯入 / 綁定 thread

以 cwd 匯入 Codex 歷史;use <thread> 接既有對話。

L · Codex 裝置登入

!tb login/logout;未登入不啟動 turn。

N · ACL 角色 + 稽核

allowed / admin / user + audit_log(現有 allowlist 擴為角色)。

安全姿態(MUST)

預設 read-only

unlock 時限切 workspace-write;寫入限 AgentHub、拒網路;lock/kill + 閒置自動 suspend。

永遠需批准

破壞性 / 網路 / 機密 / 提權 / git 改寫;危險操作導到自己聊天。

去識別

對外訊息與日誌掃除 token/cookie/env;群組只給摘要。

身分 & 稽核

不可變 sender id 授權;附加式稽核;條款風險需知情。

現況
